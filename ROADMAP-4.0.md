## Направление

Matte Slate остаётся основой (поверхности, один акцент, лестница глубины).
Добавляется: свет от обложки на всём экране; один плеер в трёх размерах
(мини → полоса → сцена) как «островок», который перетекает; стекло только для
слоёв поверх контента; одна оболочка ПК/телефон на общих примитивах; пять
глаголов движения с одной кривой и одной шкалой длительностей.

## SoundCloud

Причина хронических поломок — ключ `client_id` добывался каждым устройством из
сборок soundcloud.com. Сделано (сессия 1): сервер держит один ключ
(`server/wireon_music/soundcloud.py`, `GET /v1/soundcloud/key`, перепроверка раз
в час, поиск не чаще раза в 10 минут, `POST /v1/soundcloud/key/dead` — жалоба
клиента, сервер перепроверяет сам). Клиент (`soundcloud.ts`) спрашивает сервер
первым, вшитые ключи и свой поиск — запасной путь; при отказе ключа жалуется
серверу. После деплоя сервера проверить `/health` → `soundcloud.hasKey`.

Осталось: подмена на YouTube видна в плеере с кнопкой «вернуть оригинал»;
треки-превью (30 с) помечаются заранее.

## Аудит багов перед выпуском (копить сюда)

- [x] Linux: мини-плеер не перетаскивался. Причина: `setIgnoreMouseEvents(forward)`,
      `screen.getCursorScreenPoint()` и `setBounds` на Linux/Wayland не работают или
      работают наполовину. Исправлено (сессия 1): на Linux окно ловит мышь само, двигает
      его компоситор через `-webkit-app-region: drag` (`mini.css`, `[data-platform='linux']`),
      ручной перенос и опрос курсора выключены (`isLinux()` в `main.ts`). Проверить
      владельцу: перетаскивание на Wayland и X11, наведение и кнопки в мини-окне.
- [x] Linux: автообновление «вроде не работает». Причина: без `APPIMAGE` в окружении
      (распакованная копия, `linux-unpacked`, песочница) electron-updater отвечает на
      проверку `null` без событий, статус висел на «проверяется само». Исправлено: честное
      «нечему обновляться» (`describeUpdateSupport`), страховка от тихого `null` в `runCheck`,
      человеческий текст для ошибки про APPIMAGE. Проверить владельцу: Настройки → О
      программе, запустить сам файл `.AppImage`; `./Wireon-*.AppImage 2>&1 | grep -i updater`.
      Имена артефактов в latest-linux.yml совпадают, 3.2.0 — последняя версия, так что
      ответ «установлена последняя» сейчас и есть норма.
- [ ] Проверить все пути воспроизведения после объединения плеера: ПК, APK,
      узкое окно.
- [ ] Полный `npm run verify` и `cd server && pytest` перед `publish=true`.

## Правила для 4.0

- Длительности только из шкалы `--dur-*`, кривые только `--ease-*`; в коде
  компонентов чисел нет (следит `tests/unit/designDrift.test.ts`).
- Анимируем только `transform` и `opacity` на крупных элементах.
- Никаких подписей капсом с разрядкой и моноширинным (владелец: «нейронное уродство»,
  дизайн-система §10 про `.section-label` говорит то же). Моно — только цифры времени и код комнаты.
- Новые стили — классами и токенами, не `style={{}}`. Исключение: значения,
  которые приходят из данных (цвет обложки, ширина прогресса).
- Каждый шаг заканчивается зелёными `npm run typecheck:all` и `npx vitest run`.
