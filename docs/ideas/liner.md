# Разбор Liner 0.1.35 (tryliner.fun) — на потом

Разобран 2026-10-15 по рекламному ролику и коду из AppImage (Electron 44, React 19).

## Как устроен

- Тонкий клиент: поиск, каталог, альбомы, артисты, радио, «волна», Daily Mixes, текст песен —
  всё отдаёт их сервер `api.tryliner.fun` (`/v1/...`). Без сервера и аккаунта не работает ничего.
- Звук: `POST /v1/tracks/{id}/playback {transport: "proxy"}` → сервер сам находит звук и
  переливает его через себя. В клиенте нет ни yt-dlp, ни обращений к YouTube/SoundCloud.
- 5 логотипов в рекламе (Spotify, SoundCloud, YouTube Music, Apple Music, Deezer) — это
  откуда принимаются ссылки и импорт плейлистов, а не источники звука.

## Почему стабильнее

1. Поиск звука на сервере — YouTube что-то сломал, чинят сервер, у всех играет без обновления.
2. Следующий трек качается **целиком** заранее (Range 0-, в IndexedDB), сыгранные треки лежат в
   кэше с лимитом размера → мгновенный повтор/назад, обрывы сети не слышны.
3. Основной сервер + запасной (`edge.tryliner.fun`, по голому http): проверка `/health` с
   таймаутом 6 с при старте, выбор запоминается.
4. У сессии воспроизведения есть `expiresAt` — ссылка обновляется до истечения.

## Фичи, которых у нас нет / слабее

- Текст песни по словам и слогам (`@braccato/core`), несколько источников текста с выбором
  лучшего по точности синхронизации (plain < line < syllable < word), сдвиг таймингов в плеере.
- «Волшебная ссылка»: любая ссылка (трек/альбом/плейлист/артист, любой сервис) — открыть или
  добавить.
- Публичный профиль, лидерборды, «транслировать текущий трек», история прослушиваний.
- Пауза при смене устройства вывода, «скачать текущий трек», качество стриминга,
  управление кэшем по категориям (обложки, звук, тексты, каталог).
- Вид: «Сейчас играет» — размытая обложка на весь фон, большой текст справа; главная —
  «Good evening, имя» + плитки.

## Их минусы

- Не работает без их сервера и аккаунта.
- Установщик 180 МБ: в сборку целиком попали пакеты иконок (react-icons, solar-icons, …).
- Запасной сервер по http без шифрования.

## Что предлагали взять (по пользе)

1. Кэш звука на ПК: 2–3 следующих трека целиком заранее + сыгранные с лимитом размера.
2. Запасной путь звука через наш сервер, когда yt-dlp на ПК не справился (нагрузка на дедик —
   решает владелец).
3. Текст по словам + сдвиг таймингов.
4. «Волшебная ссылка» для Spotify / Apple Music / Deezer / YouTube Music.
5. Экран «Сейчас играет» в их стиле.
